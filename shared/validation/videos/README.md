# Validation videos

Add at least one short instructor-approved validation video to this folder
before students synchronize their forks.

Supported extensions:

- `.mp4`
- `.avi`
- `.mov`
- `.mkv`
- `.m4v`
- `.webm`

Recommended laboratory clip:

- 10–30 seconds;
- fixed camera position;
- representative target density;
- known or manually countable reference conditions;
- no private or sensitive content.
