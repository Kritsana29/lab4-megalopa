# Start Here

## Instructor

1. Replace the current repository contents using `instructor/RESET_EXISTING_REPOSITORY.md`.
2. Add the final dataset to `shared/dataset/images/` and `shared/dataset/labels/`.
3. Add validation images and video to `shared/validation/`.
4. Verify the class mapping in Session 1 (`CLASS_NAMES`).
5. Test one complete fork -> Colab -> push -> Pi clone workflow.
6. Freeze the upstream repository before students create forks.

## Students

1. Every student must have a GitHub account.
2. One designated group member creates the group fork.
3. The fork owner adds the remaining group members as collaborators.
4. Open Session 1 from the group fork and complete it in Colab.
5. Push `student_work/` to the group fork.
6. In Session 2, clone the group fork on Raspberry Pi 5 and run the USB-webcam detector.
7. Submit the two completed notebook PDFs through Google Classroom.
